# Actualités IA / AI news

Un fichier par jour, daté `YYYY-MM-DD.md`, avec un petit tour des sujets IA qui comptaient ce
jour-là — pas un flux RSS brut, une sélection courte (5-8 items) avec une ligne de contexte sur
pourquoi ça compte, en français puis en anglais dans le même fichier. Objectif : garder une trace
datée de ce qui se passait dans l'écosystème au moment où j'écrivais le reste de la bibliothèque,
pas produire un journal complet — certains jours seront plus fournis que d'autres selon ce qui
sortait réellement.

One file per day, dated `YYYY-MM-DD.md`, with a short round-up of what mattered in AI that day —
not a raw feed dump, a curated 5-8 items with a line on why each one matters, French then English
in the same file. The point is a dated snapshot of the ecosystem while the rest of this library was
being written, not a complete log — some days will be thinner than others depending on what
actually happened.
